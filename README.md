# Calculator
Calculator created using ReactJs and TailwindCss.

Four modes share one expression engine:

- **Basic** — arithmetic with operator precedence and a live result preview.
- **Scientific** — brackets, powers, trigonometry in degrees or radians,
  logarithms, roots, factorials, constants, and memory keys.
- **Programmer** — integer arithmetic and bitwise operators in hex, decimal,
  octal and binary, with every base shown at once.
- **Converter** — length, mass, temperature, volume, speed, data and time.

The keyboard mirrors the keypad in every mode: digits, operators, `Enter` to
evaluate, `Backspace` to delete, `Escape` to clear.
